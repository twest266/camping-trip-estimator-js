## About CampingMath

CampingMath packages a compact collection of trip-planning calculators into a single static web application. Rather than keeping scattered notes, half-finished estimates, and rough guesses in different places, you get one place to answer the everyday questions that come up when preparing a camping or hiking outing.

The tool suits anyone who wants straightforward math for gear, campsite setup, food and fuel needs, and trail timing. Since the whole project is a static site built on HTML and JavaScript, you can host it almost anywhere, open it in a browser, and reuse it without installing a runtime or backend.

---

## Features

- Tent sizing calculator to work out shelter requirements
- Sleeping bag temperature calculator for comfort planning on a trip
- Campsite size calculator for space and layout estimates
- Campfire wood calculator to plan firewood quantities
- Cooler ice calculator for cold-storage estimates
- Propane calculator for fuel planning
- Hiking time calculator to pace a route
- Backpack weight calculator to check your load
